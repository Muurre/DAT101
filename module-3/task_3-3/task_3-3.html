    4. Hvis en funksjon ikke returnerer noen verdi, vil variabelen vi prøver å lagre resultatet i, få verdien undefined.

  4. How do we separate parameters from each other when creating a function?

    5. Vi skiller parametere fra hverandre med komma (,) inne i parentesene.

  5. Explain how parameter names are related during the invocation and creation of a function.

    6. Parameterne i funksjonsdefinisjonen blir tilordnet verdiene som sendes inn ved kall til funksjonen, basert på posisjonen der de er angitt.

  6. Explain why a parameter is undefined when a function call is missing a parameter.

    7. Når en funksjonskall ikke inneholder en verdi for en parameter, blir denne parameteren tilordnet verdien undefined.

  7. Explain what happens when we use recursive functions.

    8. Når vi bruker rekursive funksjoner, kaller funksjonen seg selv med nye parameterverdier. Dette fortsetter helt til en stoppbetingelse er oppfylt. Hvert funksjonskall legges på stakken og avsluttes etter hvert.
